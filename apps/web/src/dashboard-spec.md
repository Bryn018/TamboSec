# TamboSec Dashboard Spec (next implementation step)

## Views
1. Overview
   - Open findings by severity
   - Recent audit events
   - Pending remediation approvals
2. Findings table
   - Filters: severity, status, source, category
3. Remediation queue
   - Approve/Reject actions with reason
4. Audit timeline
   - Immutable event feed

## Design direction
- Dark modern security console
- High contrast severity chips
- Fast scan readability over decoration
