# TamboSec MVP Roadmap

## Phase 1 (Week 1): Foundation
- Monorepo scaffold (api, web, worker)
- Shared config + lint + formatting
- Postgres + Redis local compose
- Tenant/auth schema draft

## Phase 2 (Week 2): Core Detection
- Google Workspace connector (read-only posture checks)
- Asset scanning job pipeline
- Findings normalization (severity, status)

## Phase 3 (Week 3): Action Layer
- Slack alerting integration
- Approval queue
- Remediation actions (password reset, revoke admin role, revoke sessions)

## Phase 4 (Week 4): Hardening + Pilot
- Audit trail enforcement
- Dashboard UX polish
- Security controls review
- Staging deploy on GCP
